About Us

Hus Index is a platform designed to help users explore and analyze housing prices in Seattle, USA. By presenting real estate data in a clear and structured way, the service enables potential buyers to compare properties, understand market trends, and make well-informed decisions.

The website provides the user an overview of available properties, including information such as price, location, size and number of bathrooms and bedrooms. Users can also use features such as sort and filter to find homes that matches their preferences.

This website was developed as port of a web systems and desigen course with the goal of demonstrating professinal and responive desigen, structured data presentation and user centered interface design.
